# Q-Souls-1

1. Download and extract this repository's GitHub ZIP, or clone the repo.
2. Open `_launch-Q-Souls-1.exe`, the rest is self-explanatory.
3. The launcher can keep the mod up to date.

Features:
Startup intro is skipped
All starting classes: SL 1, Vitality 12, every other stat 10
Level Up & Respec at every bonfire, including the tutorial: use the original Level Up screen to redistribute stats for free or buy levels with souls.
The Free Points row shows points left to reassign. Uses the game's normal controls and translations in all 13 languages.
Travel to Cursed Arena from Firelink Shrine: a 48 m circular arena with rolling rises and hollows, weathered stone patches, tall grass and five rocks for cover, a raised round bonfire platform, and lava falling into darkness.

Start menu opens with Equipment selected.

Bonfire menu: Q Souls opens a black settings screen. Use up/down to select a setting and left/right to adjust it: FPS (30, 60 default, 120, 240), FOV (Y axis: 40-68 degrees in steps of 4; default 48) and Camera Distance (50-200% in steps of 10, then 225%, 250%, 275%, 300%; default 100%). Default values are marked "(default)". Changes save automatically and apply immediately. Disable VSync in PC settings for high FPS.
